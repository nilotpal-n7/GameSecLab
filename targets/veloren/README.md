# Target: veloren (voxel_rust category)

Veloren — open-source Rust voxel game, used for live memory-analysis practice (not VM-protected).

The reusable methodology (pointer-path discovery, scan workflow) is category-level in
`categories/voxel_rust/` (`veloren_health_pointer.md`, `veloren.md`). The raw scan data
(`.scandata`, `.PTR` results, ReClass project) was large and regenerable and has been removed; re-run
a fresh scan against your own local Veloren client to reproduce it, following the category notes.

Nothing is tracked here but this note — scans are per-session and local.
